Straightforward workflow

From USB cable to controlled motion

Connect

Select the serial device and let the app verify a GRBL status or startup response.

Prepare

Jog, home, set the work zero, and configure conservative feed and power values.

Preview

Open G-code or generate a raster, then inspect the path and dimensions before transmission.

Run

Stream one acknowledged line at a time while monitoring progress, state, and console output.

Try it safely

No controller? No problem.

Demo mode simulates a connected GRBL controller and loads a small calibration frame. It is ideal for evaluating the interface, testing changes, and capturing screenshots.

  • No serial port is opened.
  • Jogging updates simulated work coordinates.
  • Jobs receive automatic acknowledgements.
  • Pause, resume, abort, preview, and console remain active.

Safety first

Software is not a physical safety system.

Use a suitable enclosure, wavelength-rated eye protection, effective exhaust ventilation, continuous supervision, and a physical emergency stop that removes laser power. Never process an unknown material.
