# Security Policy

## Supported versions

Security fixes are applied to the latest released version and the `main` branch.

## Report a vulnerability

Do not open a public issue for a vulnerability that could expose users, damage equipment, or create unsafe machine behavior.

Use GitHub's private vulnerability reporting page:

https://github.com/alexkypraiou/LaserGRBL-MacOS-Controller/security/advisories/new

Include:

- A clear description and realistic impact.
- The affected version or commit.
- Reproduction steps or a proof of concept.
- Relevant controller, firmware, and macOS details.
- A suggested remediation, if available.

Please allow reasonable time for investigation and a coordinated fix before public disclosure.

## Safety-critical behavior

Unexpected laser activation, failure to stop streaming, incorrect real-time command handling, or unsafe output after disconnect should be reported privately as security and safety issues.
